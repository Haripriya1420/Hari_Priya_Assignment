# Janitri Backend Assignment

## Overview
This project is a backend system for monitoring patients' heart rate data using **Spring Boot**. It includes user management, patient management, and heart rate tracking functionalities.

## Features
- **User Registration & Login** (Basic email & password validation)
- **Patient Management** (Add, retrieve patient details)
- **Heart Rate Data Management** (Record & retrieve heart rate data)
- **Robust error handling & validation**

## Tech Stack
- **Backend**: Java, Spring Boot
- **Database**: MySQL / H2 (as per your setup)
- **Build Tool**: Maven
- **Version Control**: Git, GitHub
